S 320 Portfolio Reflection
How can I ensure that my code, program, or software is functional and secure?

I can ensure that my software is functional and secure by following software development best practices, including thorough testing, code reviews, and validation of user input. Throughout this course, I learned the importance of creating unit tests to verify that classes and methods behave as expected under both normal and exceptional conditions. Testing helps identify defects early and ensures that software meets requirements. Security can be improved by validating data, enforcing constraints, handling exceptions appropriately, and designing software that prevents unauthorized or invalid operations.

How do I interpret user needs and incorporate them into a program?

I interpret user needs by carefully reviewing requirements and identifying the functionality that users expect from the software. Once the requirements are understood, I translate them into classes, methods, and validation rules within the application. During this course, I used the provided requirements to create contact, task, and appointment services that enforced specific business rules. By aligning the design and testing process with the requirements, I can ensure that the final product meets user expectations and performs the intended functions.

How do I approach designing software?

I approach software design by first analyzing the requirements and breaking the problem into smaller, manageable components. I then identify the classes, attributes, and methods needed to support the required functionality. Encapsulation, modularity, and maintainability are important considerations throughout the design process. In this course, I designed software using separate service and data classes, which improved organization and allowed for focused testing of each component. Creating unit tests alongside development also helped validate design decisions and ensure the software functioned correctly.
